## Репозиторий и сайт
- GitHub: `antoha17/remont` — ПУБЛИЧНЫЙ (Антон открыл 2026-11-04). Никаких данных клиентов, ключей и реальных цен в репозитории.

  `main` через git push прокси отклонил — её создал инструмент GitHub `create_branch` (2026-11-04).

## Устройство кода
- Исходники: `src/app.html` (интерфейс, план 2D/3D, смета, база, Excel) и `src/ai.js` (всё про ИИ).
- Сборка: `python3 scripts/build.py` → `dist/Ремонт_смета.html` + `.zip` (файл для диска) и сайт в корне:
  `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192/512.png`, `apple-touch-icon.png`. Собранные файлы коммитить.
- Встроенные библиотеки в `vendor/`: SheetJS 0.18.5 (из проекта dashboard), three.js r160 (из build/three.min.js
  вырезан console.warn, добавлен `void`), pdf.js 3.11.174 + его worker встроен обычным `<script>`
  (Worker из blob в file:// не запускался → pdf.js работает в основном потоке через globalThis.pdfjsWorker).
- CSP в шапке: `connect-src` только адреса ИИ-сервисов. Добавляя сервис — дописать туда.
- Данные: localStorage (`remont.project.v1`, `remont.materials.v1`, ключ ИИ — `remont.ai`), у каждого устройства свои.
  Перенос объекта — файл `.remont.json`. Синхронизации между устройствами нет.

## ИИ
- По умолчанию OpenAI, модель `gpt-5.4-mini` (у Антона есть ключи). Для OpenAI НЕ передавать `max_tokens`
  (модели GPT-5+ его не принимают). Anthropic — заголовок `anthropic-dangerous-direct-browser-access`.
- Все 5 сервисов (OpenAI, OpenRouter, Anthropic, Gemini, DeepSeek) разрешают запросы из браузера — проверено 2026-11-04.
- Функции ИИ: план из PDF/фото, смета заказчика + сравнение, подбор материалов из базы, чат.
- С настоящим ключом ничего не проверялось — только подставные ответы (`scripts/smoke_ai.js`, `scripts/smoke_site.js`).
