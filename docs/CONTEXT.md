# Текущее состояние

## Задача
Инструмент для прораба: чертёж объекта (вид сверху с размерами), 3D-просмотр (весь объект и каждая комната),
ввод замеров (стены, высота, двери, окна), своя база материалов с ценами из Excel, расчёт количества и суммы.

## Решения (принято при первой версии, можно менять)
- Формат: один HTML-файл, работает без интернета, на ПК и телефоне. Данные объекта автоматически хранятся в браузере;
  объект можно сохранить в файл `.remont.json` и открыть на другом устройстве.
- Размеры вводятся в метрах (запятая или точка).
- Комната: прямоугольник (длина × ширина) или сложная форма — обход стен по часовой: направление + длина.
- Проёмы: дверь / окно / проём без двери — номер стены, отступ от начала стены, ширина, высота, высота от пола.
- Считается по комнате: пол, потолок, стены без вычета и за вычетом проёмов, периметр, плинтус (периметр минус двери и проёмы),
  откосы окон и дверей (2×высота + ширина), объём, число окон и дверей.
- Позиция сметы: основа («считать по») × расход на 1 ед. × (1 + запас %) → делится на фасовку и округляется вверх
  (без фасовки — по желанию «целыми»). Блок «Общее на объект» считает от суммы всех комнат.
- База материалов: Excel, колонки ищутся по смыслу: Наименование, Цена (обязательно), Ед. изм., Категория, Расход, Фасовка,
  Считать по, Артикул. Все листы; строки-заголовки разделов становятся категориями. Цена в смете — снимок,
  кнопка «Обновить цены по базе» подтягивает новые.
- Выгрузка сметы в Excel (листы: Сводная, По комнатам, Замеры), печать.
- 3D — встроенная библиотека three.js; вращение мышью/пальцем, масштаб, «низкие стены», «только комната».

## ИИ (v2, по просьбе от 2026-11-04)
- Настройки «⚙ ИИ» как в проекте Menu_products: сервис (OpenRouter / Anthropic / OpenAI / Gemini / DeepSeek), ключ,
  модель (кнопка «Список моделей» загружает модели с сервиса; 📷 — читает фото), «Проверить связь».
- «📄 План из PDF/фото» (вкладка 1): PDF превращается в картинки (pdf.js, до 8 стр.), ИИ возвращает комнаты
  (стены R/D/L/U + длины, проёмы, положение на плане). Режим: заменить или добавить. После — блок проверки:
  заметки ИИ, сравнение площади с подписанной на схеме, незамкнутые контуры, просмотр схемы, «Отменить».
- Вкладка 4 «Смета заказчика»: фото/PDF → ИИ переписывает строки (раздел, наименование, тип материал/работа/прочее,
  ед., кол-во, цена, сумма, итог). Таблица редактируется. Сравнение с расчётом: итоги, «запас / не хватает»,
  пары «мой материал ↔ строка сметы» (авто по словам, вручную или «Подобрать пары с помощью ИИ»), красным — не влезает.
- Вкладка 5 «Чат с ИИ»: ИИ получает данные объекта (замеры, сметы, итоги, база цен; если база > 400 позиций —
  только похожие на вопрос). Переписка хранится в объекте. Быстрые вопросы.
- Проверено только на подставных ответах (настоящего ключа нет). С настоящим ИИ — не проверено.

## Подбор материалов ИИ (сделано 2026-11-04 по просьбе)
- Вкладка 2, кнопка «🤖 Подобрать материалы ИИ»: выбор комнат, «опираться на смету заказчика», пожелания.
  ИИ берёт ТОЛЬКО позиции из базы пользователя (по номеру), задаёт «считать по», расход, фасовку, запас, пояснение.
  Показывается таблица с галочками и пересчётом; дубли (уже есть в смете) — без галочки; «Нужно, но нет в базе» — списком.
  «Добавить отмеченные в смету». База до 1500 позиций уходит целиком, больше — самые похожие на смету/пожелания.

## Ответы Антона (2026-11-04)
- ИИ: есть ключи, модель **gpt-5.4-mini** (OpenAI). Сделано по умолчанию: сервис OpenAI, модель gpt-5.4-mini.
  Для моделей OpenAI не передаётся лимит max_tokens (новые модели его не принимают).
- Формат: **сайт по ссылке**, с любого компьютера и телефона. Сборка кладёт `index.html`, `sw.js`, `manifest.webmanifest`
  и значки в корень репозитория (GitHub Pages). На телефоне ставится «на экран Домой», открывается и без интернета.
- Данные хранятся в браузере каждого устройства отдельно (как в Menu_products); перенос — «Сохранить в файл / Открыть».
  Синхронизация между устройствами — не сделана (нужно облачное хранилище), только как идея.
- Пример схемы/сметы и данные по замерам/Excel — пока нет, ответит позже.

## Открытые вопросы к пользователю
1. Как зять обычно меряет: в метрах или сантиметрах/миллиметрах?
2. Как выглядит его Excel с ценами (какие колонки)? Есть ли в нём нормы расхода?
3. Нужны ли в смете работы (цены за м² работ), а не только материалы?
4. Где будет пользоваться: телефон на объекте, ноутбук, или оба?
5. Нужны ли косые стены (не под 90°), ниши, короба, наклонные потолки?
6. Пример схемы и сметы (без данных клиента) — ждём.
7. Решено: репозиторий публичный, сайт публикуется из ветки `main` (корень). Адрес https://antoha17.github.io/remont/

## Идеи (не делать без команды)
- Наборы работ («Ламинат под ключ» = ламинат + подложка + плинтус + укладка) одним нажатием.
- Отделка стен до заданной высоты (плитка до 1,5 м), разные отделки на разных стенах.
- Раскладка плитки/ламината на плане.
