# Текущее состояние

## Задача
Инструмент для прораба: чертёж объекта (вид сверху с размерами), 3D-просмотр (весь объект и каждая комната),
ввод замеров (стены, высота, двери, окна), своя база материалов с ценами из Excel, расчёт количества и суммы.

## Решения (принято при первой версии, можно менять)
- Формат: один HTML-файл, работает без интернета, на ПК и телефоне. Данные объекта автоматически хранятся в браузере;
  объект можно сохранить в файл `.remont.json` и открыть на другом устройстве.
- Размеры вводятся в метрах (запятая или точка).
- Комната: прямоугольник (длина × ширина) или сложная форма — обход стен по часовой: направление + длина.
- Проёмы: дверь / окно / проём без двери — номер стены, отступ от начала стены, ширина, высота, высота от пола.
- Считается по комнате: пол, потолок, стены без вычета и за вычетом проёмов, периметр, плинтус (периметр минус двери и проёмы),
  откосы окон и дверей (2×высота + ширина), объём, число окон и дверей.
- Позиция сметы: основа («считать по») × расход на 1 ед. × (1 + запас %) → делится на фасовку и округляется вверх
  (без фасовки — по желанию «целыми»). Блок «Общее на объект» считает от суммы всех комнат.
- База материалов: Excel, колонки ищутся по смыслу: Наименование, Цена (обязательно), Ед. изм., Категория, Расход, Фасовка,
  Считать по, Артикул. Все листы; строки-заголовки разделов становятся категориями. Цена в смете — снимок,
  кнопка «Обновить цены по базе» подтягивает новые.
- Выгрузка сметы в Excel (листы: Сводная, По комнатам, Замеры), печать.
- 3D — встроенная библиотека three.js; вращение мышью/пальцем, масштаб, «низкие стены», «только комната».

## ИИ (v2, по просьбе от 2026-11-04)
- Настройки «⚙ ИИ» как в проекте Menu_products: сервис (OpenRouter / Anthropic / OpenAI / Gemini / DeepSeek), ключ,
  модель (кнопка «Список моделей» загружает модели с сервиса; 📷 — читает фото), «Проверить связь».
- «📄 План из PDF/фото» (вкладка 1): PDF превращается в картинки (pdf.js, до 8 стр.), ИИ возвращает комнаты
  (стены R/D/L/U + длины, проёмы, положение на плане). Режим: заменить или добавить. После — блок проверки:
  заметки ИИ, сравнение площади с подписанной на схеме, незамкнутые контуры, просмотр схемы, «Отменить».
- Вкладка 4 «Смета заказчика»: фото/PDF → ИИ переписывает строки (раздел, наименование, тип материал/работа/прочее,
  ед., кол-во, цена, сумма, итог). Таблица редактируется. Сравнение с расчётом: итоги, «запас / не хватает»,
  пары «мой материал ↔ строка сметы» (авто по словам, вручную или «Подобрать пары с помощью ИИ»), красным — не влезает.
- Вкладка 5 «Чат с ИИ»: ИИ получает данные объекта (замеры, сметы, итоги, база цен; если база > 400 позиций —
  только похожие на вопрос). Переписка хранится в объекте. Быстрые вопросы.
- Проверено только на подставных ответах (настоящего ключа нет). С настоящим ИИ — не проверено.

## Новая схема разделов (2026-11-04, по словам Антона)
- Порядок в компании: компания сама считает первоначальную смету и согласует её с заказчиком → эта смета (материалы + работы)
  живёт в нашем разделе «Смета». После выполнения — «Акт выполненных работ»: итог по факту, показать заказчику;
  разница с согласованной сметой работ = доплата (или меньше сметы).
- Сделано:
  - Вкладка 2 «Смета»: «Материалы» (расчёт по комнатам, как было) + «Работы — согласованная смета» (P.works):
    загрузка Excel (без ИИ, колонки по смыслу, разделы и «Итого» распознаются), PDF/фото (ИИ), строки вручную;
    итог «материалы + работы».
  - Вкладка 4 «Смета заказчика» заменена на «Акт выполненных работ» (P.act): «Заполнить из сметы работ» (строки
    переносятся с привязкой), правка факта, «+ Доп. работа», загрузка готового акта (Excel/PDF/фото); у каждой строки —
    строка сметы и разница; итог «Заказчику доплатить» / «Меньше сметы на»; «Есть в смете, но нет в акте»;
    выгрузка акта в Excel. Акт сравнивает ТОЛЬКО работы (строки «материал» из сметы не переносятся и не считаются;
    «прочее» — считается). Печати акта нет (решение Антона: всё только для своих расчётов, заказчику не печатаем).
  - Старое сравнение «мои материалы ↔ смета заказчика» убрано; старые данные P.client переносятся в смету работ.
  - Подбор материалов ИИ опирается на смету работ; чат знает смету работ и акт.
- Договорились: Антон сначала сам пробует загрузку своих файлов в программе; присылает файл (без данных клиента) только если
  что-то не распозналось или прочиталось неверно — тогда подгоняем разбор под его формат.
- Решено: форма акта (КС-2 и т. п.), реквизиты, подписи, печать — НЕ нужны, не предлагать. Программа — для расчётов Антона.

## Сделано 2026-11-04 (по этому правилу)
- Вкладка «Смета»: сверху «Материалы — исходная смета» (загрузка Excel/PDF/фото, P.mats, скидка), затем «Работы — исходная
  смета» (P.works), общий итог «материалы + работы», внизу свёрнутый блок «Проверка: свой расчёт материалов по комнатам».
- Шаблон-прайс материалов (все отметки 0, итог 0 — итоги в файле считаются SUMIF по колонке A = 1) в смету не грузится —
  подсказка «это прайс, его место в базе». Заполненная смета (A = 1 у выбранных) грузится только выбранными строками.
- Комнаты из сметы работ: в шапке листа-помещения L, B, H, «Проем, м2», периметр, площади → кнопка «📋 Комнаты из сметы»
  (и предложение сразу после загрузки сметы). Комната: прямоугольник L×B, высота H, «Проёмы общей площадью», «Поправка
  площади пола» (как в смете) — площади совпадают со сметой. В «Расчёт по комнате» — сверка «По смете работ» (✓ или расхождение).
- План: подписи с белой обводкой, размер подписи по размеру комнаты, размеры стен — у выбранной снаружи, у остальных внутри
  и только если комната крупная; при наложении комнат — предупреждение и «Разложить без наложений».
- Вид «Проект»: PDF/фото проекта как картинка с листами и масштабом; хранится на устройстве (IndexedDB), в файл объекта
  не попадает (в объект — только текст листов для ИИ, P.project.text). Распознавание плана берёт листы из проекта.
- Чат: смета (главный источник), размеры помещений из сметы, текст проекта.

## Форматы документов компании (разобраны 2026-11-04 на примерах Антона; данные клиентов не сохранялись)
### База материалов («Исходная смета по материалам», Google-таблица → скачать как .xlsx)
- Лист «Печать»: шапка документа, затем таблица: ID | Товары (работы, услуги) | ед. изм. | кол-во | цена | сумма | вес за ед кг | итого вес.
  Разделы — строки с названием и повтором «ед. изм. / кол-во / цена…»; «Итого по разделу»; кол-во везде 1 (это прайс).
  ~1190 позиций, 13 разделов. Файл ~53 МБ из-за картинок — загрузка ~15–20 с (показывается «Читаю…»).
- Сделано: разделы → категории, «Итого/Скидка» пропускаются, ID → артикул (поиск по нему), вес за ед. сохраняется
  (в смете материалов показывается общий вес — для доставки/подъёма), скрытые листы не читаются.
- Вкладка «База»: показываются все позиции порциями по 300 («Показать ещё» / «Показать все»), фильтр по разделу, счётчик «Найдено».
### Смета работ (.xlsm, шаблон компании)
- Листы-помещения (Перегородки, Прихожая, Коридор, Комнаты, Кухня, Туалет, Ванная, Лоджия) + Отопление, Сантехника,
  Электромонтаж, Спецмонтаж; «Свод» (итоги по помещениям, «Скидка, %»), скрытые прайсы и пустые листы.
- На листе — шаблон на сотни работ; В СМЕТУ ВХОДЯТ ТОЛЬКО СТРОКИ С «1» в колонке-отметке (сумма отмеченных = итог листа).
  Колонки: наименование | ед. изм. | кол-во | цена | сумма | цена (мастер) | сумма (мастер). Заголовки повторяются у каждого
  раздела (Демонтажные / Черновые / Чистовые / Электромонтажные / Сантехнические / Подготовительные), подразделы (Полы, Стены…).
  Вверху листа — размеры помещения (L, B, H, проём), периметр, площадь пола и стен.
- Скидка 10% на всё, кроме «Спецмонтажа» (там нет строки СКИДКА).
- Сделано: разбор по этим правилам без привязки к конкретным названиям; строки получают «помещение» (= лист) и раздел;
  таблица сгруппирована по помещениям с подытогами; скидка (поле «Скидка, %», строки листов без скидки помечаются);
  акт считает «доплатить» с той же скидкой; сопоставление акта со сметой — с учётом помещения.
  Проверено на примере: итог и скидка совпали с файлом до копейки.
- Колонки «цена/сумма мастера» пока не используются (идея: показывать, сколько платить бригаде).
### Проект квартиры (PDF, 6 листов)
- Листы: титул, ОБМЕРНЫЙ ПЛАН, мебель, светильники, управление освещением, электрооборудование.
  Обмерный план: размеры в мм, у каждой комнаты «H - 2660 мм» (высота), окна «Н проема окна / Н подоконника»,
  двери «Н проема / Н порога», таблица «Экспликация помещений» (№, название, площадь, итог). Текст PDF — в старой кодировке.
- Сделано: текст PDF чинится (Windows-1251), лист «Обмерный план» выбирается сам, у листов показываются названия;
  ИИ получает общий вид + 4 увеличенных фрагмента (мелкие размеры читаются) + текст PDF; инструкция для ИИ учитывает
  экспликацию, H помещений, окна/подоконники, двери/пороги; после распознавания — сравнение общей площади с экспликацией.
  С настоящим ИИ не проверено (нет ключа).
- Идеи: по листу электрооборудования считать розетки/выключатели для электромонтажа; сверять площади плана со сметой работ.
