# Инструкция для Claude (читается автоматически)

Проект Антона: офлайн-программа для прораба (зять Антона) — план объекта с размерами, 3D-просмотр,
своя база материалов с ценами из Excel и расчёт сметы (сколько материала и на какую сумму).

## Перед началом работы
1. Прочитать `docs/CONTEXT.md` (актуальное состояние, решения, очередь, открытые вопросы).
2. Прочитать `docs/HISTORY.md` (хронология обсуждений).
3. Не переспрашивать решённое.

## Во время работы
- После каждого решения/правки обновить `docs/CONTEXT.md` и дописать `docs/HISTORY.md`, commit + push.
- Делать только то, что попросили; идеи — предлагать словами.

## Общение
- По-русски, просто, коротко, без жаргона. Пользователь не программист, часто диктует голосом.
- Честно: «проверено» — только если реально проверено. Вопросы — пронумерованные.

## Ограничения
- Один HTML-файл, полностью офлайн: никаких сетевых запросов и CDN; библиотеки встроены (SheetJS, three.js).
- Цены — только из Excel пользователя, ничего не искать в интернете.
- Не класть в репозиторий реальные данные клиентов/объектов. Тестовые данные — выдуманные.

## Сборка и проверка
```bash
python3 scripts/build.py                      # → dist/Ремонт_смета.html и .zip
python3 scripts/make_test_prices.py /tmp/prices.xlsx
LANG=C.UTF-8 LC_ALL=C.UTF-8 node scripts/smoke.js /tmp/prices.xlsx /tmp/rshots
```
Ожидается: `errors: []`, `network requests: []`, ширина 390 без горизонтальной прокрутки.
Отдавать пользователю оба файла: `dist/Ремонт_смета.html` и `dist/Ремонт_смета.zip`.
